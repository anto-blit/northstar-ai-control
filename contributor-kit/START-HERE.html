NorthStar · Start here

One idea is enough to start.

Can stories and moral principles help AI behave better? Help us test that idea. You do not need to code, run a model or create a GitHub account.

Your first contribution — about five minutes

  1. Extract the ZIP and open the extracted folder.
  2. Open FIRST-IDEA.txt in a text editor. Answer its three short questions and save your copy.
  3. Paste your idea into an email or attach your saved file. Send it to info@calibratedvision.com, the project maintainer's inbox.

Get the three-question worksheet

Email is not posted publicly. A reviewer may ask you to clarify or develop the idea; it is not an accepted finding just because you sent it. Nothing in this kit sends messages automatically.

Want help developing your idea?

Paste the starter prompt into a fresh AI chat you already use, or use the guided proposal builder without an AI account. Review the draft, then send it by email.

Prefer a public conversation? The research form accepts ideas and findings. That route requires a GitHub account.

The evidence is optional

The mislabel-v1 folder contains a saved reporting-error case: an AI labeled a refusal as compliance. It is a different case from the homepage's unauthorized email. Its historical files are preserved unchanged.

Read START-HERE.md in a text editor for the file map, optional Python check, expected success output and advanced testing instructions. Python is not needed to read the files or send an idea.

Follow what happens next

Ask for occasional updates in your email, or read the project updates and feed. Email requests are handled manually; ask to stop at any time.

This welcome page works offline. Website and email links need an internet connection or an email app. It has no tracking, external assets or model calls.
