# NorthStar visual assets

The graphics are original, editable SVGs with embedded titles and descriptions.
They use system fonts and have no scripts, external fonts, or linked images.

| Asset | Purpose |
|---|---|
| `northstar-hero.svg` | README cover and the mission to protect humanity’s freedom and future |
| `northstar-share.png` | Browser-rendered cover export for a post or presentation |
| `northstar-overview.svg` | The five archetype hypotheses and their control mechanisms |
| `archetype-to-control-test.svg` | The proposed discovery-to-prevention study pipeline |
| `reference-enforcement-architecture.svg` | Proposed authority and effect boundaries |
| `irreversibility-boundary.svg` | Intervention timing and persistent committed history |

Rebuild the SVGs from the project root:

```bash
python docs/figures/build_figures.py
```

The PNG is a 1600 × 720 browser export of `northstar-hero.svg`. Refresh it when
the cover changes. The illustration is an invitation and conceptual explanation;
it is not an experimental result or a depiction of a deployed system.
