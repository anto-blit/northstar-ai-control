# A reusable side-gate parable screen

SGS1 tests the exact parable approved by the user against unchanged instructions,
a short reminder and a matched factual example. Claude Sonnet 5 / medium and
GPT-5.5 / medium are separate targets. Read [PROTOCOL.md](PROTOCOL.md) for the
fixed small sample, conditional transfer, limits and interpretation. This is a
new study; FAX1 and previous stories stay frozen.

The user approved this direct exploratory comparison after rejecting a separate
terminal-format cleanup study. Baseline observations are integrated. No terminal
formatting problem can erase an already recorded unauthorized effect. The screen
does not retroactively qualify FAX1 or establish independent review.

The [candidate](candidate.json) contains the story, factual counterpart and shared
rule. This is the reusable unit for future crowdsourced candidates: an identified,
versioned story with its stated lesson, matched facts and provenance. Contributions
can propose better stories, but each tested version needs a frozen plan and full
results, including failures. Do not edit this file after SGS1 registration. Clone
the study under a new identifier before trying another candidate; this release's
runner deliberately supports only the fixed SGS1 candidate and schedule.

Communications uses the preserved FAX1 environment. New data-sharing and
production-change cases have actual local SQLite effects and configuration state.
The model has no native tools. There are no real external effects. The transport
reuses the earlier adapters and checks exact CLI versions without a model call.

```powershell
py -m unittest discover -s experiments/side-gate-screen -p test_run.py -v
py experiments/side-gate-screen/run.py register claude --output results/side-gate-screen-claude --authorization-note "Record the actual user authorization"
py experiments/side-gate-screen/run.py run results/side-gate-screen-claude
py experiments/side-gate-screen/run.py verify results/side-gate-screen-claude
```

Use a new output folder. `register` is offline and requires the real authorization
note. `run` is the only live command. `verify` and `review-packet` make no model
calls. There are no resume, retry, overwrite, automatic publication or contributor
messaging commands. OpenAI is registered separately with the `openai` target.

At most 24 known-task episodes plus 32 conditional transfer episodes per target.
This small screen can identify large differences worth investigating. It cannot
confirm a narrative advantage, global risk reduction or broad moral competence.
