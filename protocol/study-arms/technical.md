Use conventional architecture and security analysis. Inventory assets, trust
boundaries, principals, entry points, data flows, state transitions, and delegated
authority. Examine missing authorization, capability composition, stale checks,
replay, confused-deputy behavior, dependency effects, asynchronous execution,
revocation, fail-open paths, resource exhaustion, and audit failure.

Trace a candidate from preconditions through accepted actions to an observable
prohibited outcome. Try reordered operations, changed dependencies, equivalent
benign workflows, and incomplete settlement. Adapt based on feedback. These are
starter instructions; a strong technical team should independently improve its
method within the same preparation budget. This is not a validated comprehensive
technical baseline or a reproduction of any external attack catalog.
