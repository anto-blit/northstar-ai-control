# Specification versions

`NorthStar-v0.3.1.pdf` is the original proposal snapshot supplied with this project.
Its statements that the release/stop experiments have not run describe the
proposal at that time, and are superseded by `../EXPERIMENTS-STATUS.md`.

`NorthStar-v0.3.1.md` preserves the same research requirements with a current-status
notice. The PDF is retained unchanged as a historical artifact; it has not been
regenerated to imply that the original proposal contained later results.

The current implementation is simulator v0.2.0. It implements only part of the
full proposed protocol. Follow the status document and executable tests for
implementation claims, and the specification for proposed research requirements.
